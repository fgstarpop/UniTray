第7章 白瞎了一片秃头！
听着周围的议论声，虞轩文化的现任CEO秦舞阳秀眉微蹙，看着那边一直和她不对付的几个人，眼神之中充满了冷意。
“自作聪明！”
她低哼了一声，脸色一整，低喝道：“都别说了，白总马上就要过来了，大家准备一下。”
一言之下，属于她这个阵营的公司高官纷纷闭口不言，脸色略微带着恭敬，等待着神秘的白总出现。
而另一边，公司的两个副总却各自冷眼相看，根本就没有让自己这边的人来迎接的意思。
“吴总，咱们这么做，会不会让白董”
有管理层心里忐忑，小心翼翼的问道。
吴总横了他一眼，大手一挥，低声说道：“你们是不是傻啊，没听说过一句话么？法不责众！难道他一个毛头小子，还有魄力对上我们这么多人？”
法不责众啊！
有道理！
一群唱反调的公司高层对视一眼之后，纷纷点头。
“叮”
电梯铃声响起，一身休闲打扮的白景轩屌儿郎当的从里面走出来。
“白总，欢迎！”
在看到他的瞬间，秦舞阳的双眸当中闪过一抹惊艳。
果然不愧是那个妖孽的弟弟，这颜值，无敌了！
而站在这边迎接他的人里面，还有不少的单身女性，在看到他的瞬间，纷纷双眸发光，仿佛是饥渴的饿狼，恨不得将他一口吞下去。
小鲜肉！小鲜肉！小鲜肉！
好鲜好鲜的小鲜肉！
这些女人，无论是没结婚的单身女郎，还是已经结婚的熟妇，脑子里面就只有这三个字在回荡。
“白总您好，我是虞轩文化现任CEO秦舞阳，未来的日子里面，将会由我辅助您掌管公司。”
秦舞阳伸出纤纤玉手，脸色平淡看不出息怒的说道。
白景轩伸手握了两秒，松开她略显冰凉的手指，看着她黑框眼镜后面精致的五官，顿时有些惊艳。
“居然还是个极品眼镜娘啊！”
心里惊叹了一句，他眼神一闪，看向了那边那群一动不动的人。
这群人看向他的眼神充斥了各种负面的情绪，只是稍一思索，白景轩就明白过来，这些人大概就是传说中的职场派系了？
“下马威吗？呵呵，以为我会很在乎这个CEO的职位？笑话！”
白景轩心中冷笑，双眼若无其事的转动，指着那群一动不动无声抗议的人，朝着秦舞阳问道：“秦总，他们是虞轩文化的人吗？如果是，就让他们给我过来。如果不是，那就让他们滚蛋！”
我去！
果然是白董的弟弟，这小暴脾气都差不多啊！
虞轩文化的高层纷纷惊叹，用期盼的眼神等待着接下来可能会爆发的大戏。
太激动了！
实在是太激动了！好想马上去买两桶爆米花啊！
其中的几个女人甚至激动得差点裤腰带都快掉了，一双眼睛里面满是对八卦的渴望之光。
秦舞阳顺着他的手指，看着那边的两个副总，还有他们手底下的那些个管理层，顿时悠然一笑。
“吴总，还有蒋总，你们都听到了没？觉得自己是虞轩文化的员工，那就赶紧过来让白总认一认。要是觉得白总不足以让你们追随，那你们就自己消失吧。哦，对了，这话可不是我说的，是白总说的！”
清脆当中带着一抹冷意的声音在虞轩文化前台大厅回荡，秦舞阳此刻就像是一只九尾狐狸一样，眼神当中充满了狡黠之意。
呵呵
一群自作聪明的人。
你们想用职位威胁人家？殊不知人家根本都没把这个市值几十亿的公司放在眼里呢。
这就相当于你想和人下棋，但对方却直接把棋盘掀了，拿菜刀架在你脖子上，问你认不认输一样。
无赖，又聪明！
秦舞阳看了一眼穿着休闲装，一脸无所谓的白景轩，眼神当中闪过一抹欣赏之色。
这个男人，很有魄力！
那边，听到秦舞阳的声音，为首的吴总和蒋总气得牙根都开始疼起来。
去，还是不去，这是一个艰难的选择啊！
突然，吴总看着白景轩的眼神一亮，和身边的蒋总低语了一句之后，两个人再次露出了胜券在握的神色，带着一群有些懵比的手下，浩浩荡荡的朝着这边走来。
“呵呵还要垂死挣扎一下么？”
秦舞阳怜悯一笑，看着两个中年男人头顶秃掉的一片，喟然长叹。
真的是白瞎了你们这一大片秃头了啊，鼠目寸光，连现在基本的形势都看不出来！
