第3章 这个交代，够不够？
“你你你”
白景轩一米八多的个头，压迫性的气势下，只有一米七不到的KTV服务员顿时就像是被电了一样，结结巴巴的不知道说什么好。
“还不快去！”
森冷的声音回荡，白景轩冷笑一声，回头又对狄莉热芭说道：“热芭，马上打电话给我姐姐那边，既然要搞，那就搞个大的！”
他的眼神晶亮，俊朗的脸上一片冷漠，让狄莉热芭下意识的浑身一抖。
这种气质，和总裁好像啊！
都是这样冰冷，都是这样的不怒自威！
很快，KTV的经理就带着一群人浩浩荡荡的冲了过来，而狄莉热芭这边也打完了电话。
“景轩，李姐说让你随便做，只要保护好自己就行了。剩下的事情，虞轩集团在魔都的负责人会来搞定。”
狄莉热芭仰着头，温热的气息流转，声音当中带着一抹亢奋。
搞事情！
有白景虞这样一个女首富在，她们虞轩旗下的艺人哪一个会怕搞事情？
况且现在还有白景虞的弟弟在，就算是把天都捅破了，要补上去也不过是个小意思而已。
“嗯。”
白景轩点了点头，回头，面对着刚刚走近的KTV经理，语气森寒的说道：“你就是这家KTV的经理？你手底下的员工擅自泄露顾客信息，这件事情你打算怎么解释！”
KTV经理脸色一沉，看了一眼他和他身后的四个女明星，眉头一皱。
“首先，我们KTV的员工不可能泄露你们的信息，况且你们的信息有什么泄露的必要吗？其次，作为顾客损坏我们KTV的设施，您是不是应该先解释一下到底发生了什么事情？如果你给不出合理的交代，那今天休想从这里走出去！”
他的反应非常的强硬，站在他身后的十多个人高马大的安保人员更是齐齐上前一步，指骨被捏的咔咔作响。
威胁之意，溢于言表！
白景轩双眼一眯，挥了挥手，说道：“自己滚进去看！”
经理脸色一沉，裂开嘴露出残酷的笑意，阴测测的说道：“小子，看样子你是第一次来我们这里消费吧。我们帝豪，可不是你随便就能撒野的地方！”
他手一挥，身后的安保人员就直接冲了出去。
“给我把他们留下！”
说完，他带着几个服务员从侧边绕开，走进了包厢里面。
“景轩，小心！”
看着砂锅大的拳头挥舞过来，狄莉热芭和郑漺几个美女纷纷惊叫。
这一拳，正对他的太阳穴，显然这个安保是下死手了！
白景轩脸上带着冷笑，随手一拳挥出。
“砰”
一声闷响，最先出手的一个大汉抱着自己的手臂就朝后面退去。
“老子的指骨断了，这小子很强，大家一起上！”
大汉抱着自己的左手，发出凄厉的嘶吼。
白景轩裂开嘴，突然
“啊打”
一声厉吼，闪电般出手！
一时间，人影茕茕，白景轩就像是一头人形凶兽一样，在狭窄的巷道里面如入无人之境。
“砰！”
一拳，人影倒飞！
“轰”
一腿，巨大的身躯砸在红地毯上，烟尘四起！
“哐！”
一个过肩摔，又是一个人影砸在了通道边上的花盆上！
惊骇！惊骇！
只是几十秒的时间，十多个安保全部被干得失去了战斗力，躺在通道上哀嚎。
狄莉热芭几个看着这一幕，艰难的咽下了一口口水。
难道
总裁的弟弟在意志留学的时候，学得不是管理，而是格斗？
妈呀！
这简直就是个人形凶兽啊，白家姐弟果然都是变态妖孽！
“嘶吗的，蒋经理，今天必须把那个小比崽子给我留下，老子要好好修理修理他！”
震天的音乐声从门口飘出，白景轩踩在第一个出手的安保的脸上，听到了一阵凄厉的喝骂声。
臭味来袭。
KTV经理脸色极致阴沉的扶着那个王少，从包厢里面走出来，一边走，一边说道：“王少放心，那小子”
话还没说完，他就看到了走廊里面狼藉的一幕，脸色瞬间僵硬。
“砰”
白景轩一脚蹬过去，经理和他扶着的王少人仰马翻，又一次摔回了KTV包厢里面。
“草泥马！你他吗怎么回事？老子的骨头啊！”
王少凄厉的嘶吼夹杂着臭味从包厢里面传出，灯光下，白景轩依旧帅得让人发狂的脸蛋出在了他们的面前。
“这个交代，够不够？”
